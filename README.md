# เนื้อเรื่องย่อ

  คืนหนึ่ง ในวันที่อากาศไม่เป็นใจ ท้องฟ้ามืดสนิท หยาดฝนโปรยปราย เด็กน้อยในชุดกันฝนตื่นขึ้นมาพบว่าตัวเองอยู่ท่ามกลางเขาวงกตที่แสนซับซ้อน รอบข้างเต็มไปด้วยพุ่มไม้สีเขียว และเส้นทางคดเคี้ยว เด็กน้อยได้เจอกับผึ้งที่ต้นไม้ศักดิ์สิทธิ์ ทว่า ตอนนี้ต้นไม้นั้นไร้ซึ่งความมีชีวิตชีวา ผึ้งบอกกับเขาว่า “ที่แห่งนี้มีประตูทางออกอยู่ แต่ก็มีกระแสไฟฟ้ารายล้อมที่ประตูเช่นกัน ทำให้ไม่มีใครหนีออกไปจากที่นี่ได้เลย” หากอยู่ในนี้นานวันเข้า ความทรงจำจะค่อยๆ เลือนลางไป กระทั่งลืมที่จะขวนขวายเพื่อหาทางออก เด็กน้อยจะสามารถหนีออกไปจากที่แห่งนี้ได้หรือไม่ ด้านนอกเขาวงกตคือสถานที่แบบไหนกันแน่
